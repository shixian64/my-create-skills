# my-create-skills

个人维护的 Codex Skills 集合，按用途分类如下。

## 视频制作与企业汇报

- [`ai-executive-video-template`](ai-executive-video-template/)：使用锁定的企业视觉模板制作 AI 研发进展汇报视频。

## 图像与视频提示词

- [`emotion-driven-cinematic-colossal-prompt`](emotion-driven-cinematic-colossal-prompt/)：生成或优化电影级写实巨物图像与视频提示词。

## 项目管理系统集成

- [`read-jira-issue`](read-jira-issue/)：读取并分析 JIRA Issue 及其附件、历史与关联内容。
- [`read-redmine-issue`](read-redmine-issue/)：读取并分析 Redmine Issue 及其附件、历史与关联内容。
