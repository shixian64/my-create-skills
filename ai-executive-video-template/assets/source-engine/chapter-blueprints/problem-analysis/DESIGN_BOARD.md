# 传统分析方式 vs AI分析方式｜商务小黑板模板版

## Template Direction

- 参考在线 Blackboard Timeline 的“信息板 + 时间线”结构，但不使用校园粉笔字和涂鸦。
- 真实录屏作为事实证据，右上角悬浮深蓝灰色商务小黑板，显示当前步骤、序号与动作说明。
- 传统小黑板使用橙色窄边，AI小黑板使用绿色窄边；包含轻阴影、细分隔线和统一留白。
- 结尾改为完整价值看板，明确“从海量 log 中解放”“信息搬运 → 技术判断与决策”。
- 不引入第三方版权模板文件，只借鉴信息层级并本地重绘，便于后续三支 AI 能力视频复用。

## Output

- 1920×1080，30fps，H.264 + AAC。
- 总时长15秒：传统5.8秒、AI 5.0秒、价值4.7秒，两处0.25秒转场。
- Header：`#0F2F57`；Board：`#162638`；传统强调：`#D97706`；AI强调：`#16A34A`。
- 字体：Microsoft YaHei；保持大字号、强对比和老板视角可读性。

## Narration

- 传统：过去，人工下载、翻找并核对海量 log，步骤多、定位慢。
- AI：现在，提供 log 路径，AI 自动分析并输出根因。
- 收口：AI 处理海量 log，人在信息搬运中解放，聚焦根因判断和解决闭环。
