# 锁定模板合同

## 1. 模板版本

- Template ID：`sageroad-ai-executive-v1`
- 画布：1920×1080
- 帧率：30fps
- 视频：H.264 High / yuv420p
- 音频：AAC / 48kHz / mono
- 字体：`C:\Windows\Fonts\msyhbd.ttc`（Microsoft YaHei Bold）
- 品牌底图：`assets/locked/sageroad_template_bg.png`

模板资源必须通过 `assets/locked/manifest.json` 的 SHA-256 校验。不得重绘 Logo、替换背景图或用近似字体。

渲染环境必须通过 `assets/locked/environment-lock.json` 校验。FFmpeg 版本或字体哈希不同即停止，不能以“看起来接近”代替锁定环境。

## 2. 固定视觉常量

| 项目 | 固定值 |
|---|---|
| 主文本 | `#162033` |
| 次文本 | `#526171` / `#707D8B` |
| 蓝色主色 | `#005AA9` / `#2563EB` |
| 成功绿 | `#16A34A` / `#4ADE80` |
| 警示橙 | `#D97706` / `#FFB700` |
| 浅字幕底 | `#EEF5FA` |
| 深色价值条 | `#142B3E` |
| 深色看板 | `#162638` |

固定字号：主标题 56–70px，章节标题 52px，卡片主文案 36–38px，字幕 38px，说明 21–29px。不得为容纳长文案而缩小字号；应缩短文案。

## 3. 固定时间轴

- 首页：8.30 秒。
- 每个标准章节：15.00 秒。
- 最后章节：取前 11.60 秒，再冻结结果画面 2.00 秒。
- 结尾页：3.65 秒，与正文淡入 0.25 秒。
- 最终总时长：`8.3 + (章节数 - 1) × 15 + 13.6 + 3.4` 秒。

示例：1 章 25.3 秒，2 章 40.3 秒，3 章 55.3 秒，4 章 70.3 秒。

## 4. 首页规则

- 左上和右上品牌信息完全来自锁定背景。
- 顶部细线：x=160、y=112、w=1600、h=5。
- 提示：`内部 AI 应用进展`。
- 主标题默认：`AI 正在融入研发日常`。
- 1–4 章单排；5–8 章双排。
- 底部固定写“当前展示 N 个高频场景”，不得写“已覆盖”。

三章节时必须使用原版坐标：卡片 x=235/745/1255，y=410，w=430，h=210；底部蓝条 x=355、y=730、w=1210、h=115。

## 5. 标准章节片规则

每个章节片必须先独立做成 15 秒，包含：

1. 传统方式动态示例。
2. AI 方式动态示例。
3. 价值结果或工作重心变化。
4. 顶部大标题与小标签。
5. 底部浅蓝字幕条，字幕无句末标点。

章节片画面必须使用同一企业模板。传统阶段使用橙色窄边，AI 阶段使用绿色窄边；价值看板使用 `#162638` 深色面板与绿色强调线。

## 6. 结尾规则

- 小标题：`内部 AI 应用进展`。
- 主标题：`N 个高频研发场景的 AI 应用实践`，1–8 使用中文数字。
- 卡片只写结果，不写技术过程。
- 底部深色条固定写：`工程师聚焦验证 质量与决策`，除非配置明确替换为等长管理表述。
- 结尾必须完整显示并稳定停留，不得在动画未完成时结束。

## 7. 文案边界

- 首页和结尾只讲“本次展示”，不声称能力仅覆盖这些场景。
- 类别名称保持同一层级和同一口径。
- 不使用“替代工程师”“减少人员”等表达。
- 价值表述聚焦效率、质量、风险前移和工作重心转变。

## 8. 禁止项

- 禁止自行找近似 PPT 背景。
- 禁止改 Logo、页边距、字幕高度、卡片圆角、颜色和字体。
- 禁止加炫光、故障、赛博朋克、快速闪烁或复杂转场。
- 禁止把细小代码当成管理层必须读懂的信息。
- 禁止使用加速 TTS 硬塞文案。
- 禁止删除 `.locked-template-work/` 后只交一个成片；中间工程是模板可复现性的组成部分。
